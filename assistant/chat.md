# Meu Copilot no chat

## Para que serve

O Chat é onde o Copilot trabalha com a pessoa. Dá para falar com o Meu Copilot ou com um colaborador digital.

## Quem vê

Só essa pessoa conversa com o Meu Copilot. A tela marca **Só você conversa com ele**.

## Onde fica

`/chat` e `/agent/[id]/chat/[chatId]`. É a tela inicial depois do login. A barra da Torre de Controle também abre um chat já com a mensagem digitada.

## O que a tela mostra

A tela inicial cumprimenta pelo horário e apresenta o texto "Seu agente no dia a dia: consulta dados, interpreta informações, produz conteúdos e executa tarefas no seu tom."

**Nova interação** abre uma conversa. O campo pede "Escreva sua solicitação ou aperte / para atalhos rápidos." A conversa precisa de um destinatário. O Copilot da pessoa aparece como **Meu Copilot**.

{% hint style="warning" %}
Se nenhum colaborador digital estiver escolhido, o envio fica bloqueado com a mensagem "Escolha um colaborador digital para poder enviar."
{% endhint %}

**Canais do seu Copilot** mostra E-mail e WhatsApp como **Conectado**, **Não conectado** ou **Recebimento incompleto**. **Progresso de hoje** conta Respondidas, Decisões, Prazos feitos, Dispensadas e Pendentes.

{% hint style="info" %}
Quando a fila zera, a tela mostra **Fila zerada**.
{% endhint %}

## Campos

O texto da solicitação e o destinatário. Dá para anexar arquivo.

## O que dá para fazer

Continuar uma conversa, anexar arquivo, abrir voz ao vivo e usar um atalho de **Ideias para começar**. O botão do atalho é **Usar**.

{% hint style="info" %}
Mostra um rascunho e espera você mandar antes de qualquer envio.
{% endhint %}
