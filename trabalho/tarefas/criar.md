# Criar uma tarefa

Em **Tarefas**, o botão **Criar Tarefa** pede primeiro o colaborador digital que vai executar o trabalho. A tarefa fica ligada a esse colaborador.

## Campos obrigatórios

| Campo | Regra |
| --- | --- |
| Nome | Obrigatório, no mínimo 3 caracteres |
| Descrição | Obrigatória, no mínimo 3 caracteres |
| Frequência | Obrigatória. Veja Agendamento |
| Objetivo | Obrigatório, no mínimo 3 caracteres |

Conforme a frequência, a tela também pede dia da semana, dia do mês, hora da execução ou hora de início, hora de fim e intervalo.

[Agendamento](agendamento.md)

{% hint style="success" %}
A criação confirmada mostra "Tarefa criada com sucesso." A edição mostra "Tarefa atualizada com sucesso."
{% endhint %}

## Na lista

A lista e a agenda mostram a tarefa como **Ativa** ou **Inativa**. Dá para buscar, filtrar por status, colaborador e agendamento, e usar **Ativar ou desativar tarefa**.

Cada linha mostra **Próxima:** e **Última:**.

{% hint style="info" %}
Se nunca rodou, o texto é **Ainda não executou**. Se a última execução não carregar, a lista continua disponível e avisa que a última execução ficou indisponível.
{% endhint %}

## Excluir

{% hint style="danger" %}
A exclusão pede confirmação. Um snapshot vai para a Lixeira do projeto. A restauração recria a definição com novos identificadores. Canais, memória, versões e agendas não voltam. A tarefa só pode ser restaurada se o colaborador digital ainda existir neste projeto.
{% endhint %}

O desenho dos passos fica em Fluxo.
