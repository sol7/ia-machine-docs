# Conectores

Conectores ligam a plataforma às ferramentas externas.

Quem administra o projeto encontra **Conectores** no menu de orquestração.

{% hint style="warning" %}
A lista só carrega com um projeto selecionado. Sem projeto, a plataforma avisa: "Escolha um projeto no menu lateral para ver os conectores."
{% endhint %}

{% hint style="info" %}
Há três usos, e eles não se substituem.
{% endhint %}

1. **Conector do projeto.** Cadastra a ferramenta para o projeto. É a lista **Conectores** de quem administra.
2. **Conector do colaborador digital.** Na seção **Conectores** do Canvas, você vincula o que aquele colaborador pode usar.
3. **Autorização do Copilot.** No seu cadastro, a etapa **Autorizações** escolhe quais ferramentas e conectores o seu Copilot pode usar no chat e nas tarefas.

Quem administra também encontra **Conectores** no grupo **Conectividade** do menu pessoal.
