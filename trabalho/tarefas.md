# Tarefas

A tela Tarefas organiza, agenda e acompanha o trabalho dos colaboradores digitais.

Dá para ver a lista ou a agenda, buscar pelo nome e filtrar por status, colaborador e agendamento. Cada tarefa aparece como ativa ou inativa, com a próxima execução e a última.

{% hint style="info" %}
Se ainda não rodou, a lista mostra "Ainda não executou".
{% endhint %}
