# Trabalho

O trabalho da operação fica em quatro áreas do menu.

* [Tarefas](tarefas.md) organiza, agenda e acompanha o trabalho dos colaboradores digitais.
* [Artefatos](artefatos.md) organiza dashboards, relatórios, documentos e insights do projeto.
* [Conectores](conectores.md) ligam a plataforma às ferramentas externas.
* [Acompanhar o trabalho](acompanhar.md) reúne a Torre de Controle, as Atividades, as Execuções e as Interações humanas.
