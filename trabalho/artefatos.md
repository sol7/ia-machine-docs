# Artefatos do projeto

**Artefatos** fica em **Orquestração e Execução**. A lista organiza dashboards, relatórios, documentos e insights do projeto.

Dá para buscar e ver quantos artefatos e colaboradores estão ligados.

{% hint style="info" %}
Esta lista não é a caixa pessoal do Copilot. O arquivo produzido no chat aparece em **Meus artefatos**. O que outra pessoa compartilhou aparece em **Compartilhado comigo**.
{% endhint %}

## Na lista

Os botões da lista são **Criar artefato** e **Enviar arquivo**.

Um item que ainda não foi publicado aparece como **Não publicado**.

{% hint style="warning" %}
**Não publicado** continua na lista. O item está no acervo do projeto, mas ainda não foi publicado.
{% endhint %}

## Studio de Artefatos

Quando o artefato nasce numa tarefa, o nó **Artefato** abre o **Studio de Artefatos**. As etapas são:

1. **Definição**
2. **Dados e ações**
3. **Construção**
4. **Validação**
5. **Publicação**

Na definição, a tela pede o nome, o objetivo do artefato e o design system. O padrão é o design system do projeto.
