# Entrar, projeto e papéis

## Para que serve

Entrar na conta, escolher o projeto e saber o que cada papel enxerga.

## Quem vê

Qualquer pessoa com usuário. O que aparece depois depende do papel e de haver um projeto selecionado.

## Onde fica

Login e o seletor de projeto no menu lateral.

## O que a tela mostra

Várias telas só carregam depois que um projeto está selecionado. No primeiro acesso a um projeto, a plataforma pede para criar o Meu Copilot antes de liberar o uso.

{% hint style="warning" %}
Sem projeto, a lista de conectores avisa: "Escolha um projeto no menu lateral para ver os conectores."
{% endhint %}

## Campos

Usuário e projeto selecionado.

## O que dá para fazer

Entrar e trocar de projeto.

## Limite atual

| Quem | O que some |
| --- | --- |
| Viewer | Colaboradores digitais |
| Sem projeto | Colaboradores digitais, Copilots, tarefas do menu Assistant e Auditoria |
| Quem não é administrador | Conectores, Meus conectores, Robots, Runners, Usuários, Auditoria, Conta, Projetos e Chaves da aplicação |
