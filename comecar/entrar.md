# Entrar, projeto e papéis

Entrar na conta ainda não mostra a operação inteira. Primeiro existe um usuário. Depois existe um projeto selecionado. O papel decide o que esse usuário pode abrir dentro do projeto. Se uma tela some, a causa quase sempre está numa dessas três condições.

## Para que serve

Entrar na conta, escolher o projeto e saber o que cada papel enxerga.

## Quem vê

Qualquer pessoa com usuário. O que aparece depois depende do papel e de haver um projeto selecionado.

## Onde fica

Login e o seletor de projeto no menu lateral.

## O que a tela mostra

Várias telas só carregam depois que um projeto está selecionado. No primeiro acesso a um projeto, a plataforma pede para criar o Meu Copilot antes de liberar o uso. Sem isso, o chat pessoal daquele projeto ainda não tem agente.

{% hint style="warning" %}
Sem projeto, a lista de conectores avisa: "Escolha um projeto no menu lateral para ver os conectores."
{% endhint %}

O projeto não é a pasta de conversas do chat. A pasta de conversas se chama Projetos no Assistant e agrupa as suas interações. O projeto do menu lateral é o espaço da empresa.

## Campos

Usuário e projeto selecionado.

## O que dá para fazer

Entrar e trocar de projeto. Ao trocar, confira de novo as listas: colaboradores, Copilots, tarefas do Assistant e Auditoria dependem do projeto aberto.

## Limite atual

## Dúvidas comuns

**Entrei e a lista de colaboradores não aparece.**
Confira duas coisas. Se o papel é Viewer, Colaboradores digitais não entra no menu. Se nenhum projeto está selecionado, a lista também some, junto com Copilots, as tarefas do menu Assistant e a Auditoria.

**Sou da equipe e não acho Usuários, Runners nem Chaves.**
Essas telas, mais Conectores, Meus conectores, Robots, Auditoria, Conta e Projetos, ficam com o administrador. O chat e a Torre continuam disponíveis.

**Já tenho Copilot em outro projeto. Preciso preencher tudo de novo?**
No primeiro acesso do projeto novo, a tela oferece trazer o Copilot que você já tem ou começar do zero. Sem nenhum projeto selecionado, nem essa tela abre.

**O que é Expert nesse contexto?**
Na ficha do colaborador, o gestor da revisão humana só pode ser Expert ou Administrador do projeto. É quem pode ser responsável por uma decisão que o fluxo parou para uma pessoa tomar.
