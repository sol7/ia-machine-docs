# Colaboradores digitais

Colaboradores digitais são os agentes da operação. A tela lista os do projeto para visualizar e gerenciar os agentes de decisão estratégica.

Cada colaborador tem nome, descrição e um estado ativo ou inativo. A busca encontra pelo nome e pela descrição.

{% hint style="success" %}
A criação concluída mostra "Colaborador digital criado com sucesso."
{% endhint %}

Uma tarefa da operação pertence a um colaborador. Na lista de tarefas dá para filtrar pelo colaborador que executa o trabalho.

{% hint style="info" %}
O seu Copilot pessoal não aparece nesta lista como um colaborador da operação.
{% endhint %}
