# IAMachine

A IAMachine é a plataforma em que a empresa cria colaboradores digitais e acompanha o trabalho que eles fazem.

Um colaborador digital é um agente com um papel no negócio. Ele consulta informações, produz conteúdo e executa tarefas. O Copilot é o agente do dia a dia de uma pessoa. As tarefas organizam e agendam esse trabalho. Os conectores ligam a plataforma às ferramentas que a empresa já usa.

Esta documentação é para quem configura e acompanha a plataforma.
