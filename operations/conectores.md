# Conectores

Conector é a ligação da plataforma com uma ferramenta de fora. Esta página é o catálogo do projeto: a ferramenta fica disponível para o projeto e, em seguida, pode ser ligada a um colaborador ou a uma tarefa. Ela não autoriza sozinha o seu Meu Copilot, e a autorização do seu Copilot não cria este cadastro.

## Para que serve

Catálogo de conectores do projeto. Liga a plataforma às ferramentas externas.

## Quem vê

Só administrador. Quem não é administrador não vê a entrada.

## Onde fica

`/connectors`. Quem administra também encontra **Conectores** no grupo **Conectividade** do menu pessoal.

{% hint style="warning" %}
A lista só carrega com um projeto selecionado. Sem projeto, a plataforma avisa: "Escolha um projeto no menu lateral para ver os conectores."
{% endhint %}

## O que a tela mostra

Há três usos, e eles não se substituem.

1. **Conector do projeto.** Cadastra a ferramenta para o projeto. É esta lista. Criar, editar, autorizar e ligar ao colaborador ou à tarefa acontecem aqui.
2. **Conector do colaborador digital.** Na ficha, a seção Conectores vincula o que aquele colaborador pode usar. Sem o cadastro no projeto, a ficha não tem o que vincular.
3. **Autorização do Copilot.** No Meu Copilot, a etapa Autorizações escolhe o que o Copilot pode usar no chat e nas tarefas. Isso não cadastra o conector no projeto.

Meus conectores, no Assistant, é uma quarta porta: a lista do que o Meu Copilot pode usar. Também pede administrador. Não substitui este catálogo.

## Campos

Criar, editar, autorizar e ligar ao colaborador ou à tarefa. O formulário de cada ferramenta, campo a campo, ainda não está nesta página. Uma página por conector só entra quando o catálogo estiver estável.

## O que dá para fazer

Criar, editar, autorizar e ligar o conector ao colaborador ou à tarefa.

## Limite atual

Uma página por conector só quando o catálogo estiver estável. Os manuais técnicos não substituem esta página. Quem não é administrador não vê Conectores.

## Dúvidas comuns

**A lista não abre.**
Selecione um projeto. A frase da tela é: "Escolha um projeto no menu lateral para ver os conectores." Se o projeto está selecionado e a entrada não existe, o seu usuário não é administrador.

**Autorizei no primeiro acesso do Copilot e o catálogo continua vazio.**
A etapa Autorizações não cadastra a ferramenta no projeto. Crie o conector nesta lista e, se for o caso, ligue ao colaborador ou à tarefa.

**Liguei na ficha do colaborador. Meu chat pessoal passou a usar a ferramenta?**
Não. O chat pessoal depende da autorização do Meu Copilot e, para o administrador, de Meus conectores. São listas diferentes.
