# Conectores

## Para que serve

Catálogo de conectores do projeto. Liga a plataforma às ferramentas externas.

## Quem vê

Só administrador.

## Onde fica

`/connectors`. Quem administra também encontra **Conectores** no grupo **Conectividade** do menu pessoal.

{% hint style="warning" %}
A lista só carrega com um projeto selecionado. Sem projeto, a plataforma avisa: "Escolha um projeto no menu lateral para ver os conectores."
{% endhint %}

## O que a tela mostra

Há três usos, e eles não se substituem.

1. **Conector do projeto.** Cadastra a ferramenta para o projeto. É esta lista.
2. **Conector do colaborador digital.** Na ficha, a seção Conectores vincula o que aquele colaborador pode usar.
3. **Autorização do Copilot.** No Meu Copilot, a etapa Autorizações escolhe o que o Copilot pode usar no chat e nas tarefas.

## Campos

Criar, editar, autorizar e ligar ao colaborador ou à tarefa. O formulário de cada conector do catálogo não foi aberto campo a campo.

## O que dá para fazer

Criar, editar, autorizar e ligar o conector ao colaborador ou à tarefa.
