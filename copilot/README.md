# Copilots

O Copilot é o agente do dia a dia de uma pessoa. Ele consulta dados, interpreta informações, produz conteúdos e executa tarefas no tom de quem o configurou.

{% hint style="info" %}
Só essa pessoa conversa com ele. Nem os administradores do projeto veem essa conversa.
{% endhint %}

Cada projeto tem o seu. Dá para trazer um Copilot pronto de outro projeto ou criar um do zero.

O cadastro pode ser reaberto em **Perfil › Meu Copilot**.
