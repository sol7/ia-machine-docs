# Conectores

Conectores ligam a plataforma às ferramentas externas.

Quem administra o projeto encontra **Conectores** no menu de orquestração. A lista só carrega com um projeto selecionado. Sem projeto, a plataforma avisa: "Escolha um projeto no menu lateral para ver os conectores."

No Copilot, a etapa **Autorizações** escolhe quais ferramentas e conectores aquele Copilot pode usar no chat e nas tarefas. Autorizar no Copilot é diferente de cadastrar o conector do projeto: a primeira define o que aquela pessoa pode usar; a segunda disponibiliza a ferramenta no projeto.
