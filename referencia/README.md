# Referência

A Referência explica o papel de cada nó ativo do fluxo, na língua de quem desenha a tarefa. Ela não substitui o botão **Abrir manual do nó** dentro do editor. Quando esse manual tem texto, ele separa visão geral, configuração, como usar, exemplos e referência. Quando não tem, a tela diz isso com uma frase. Esta wiki não completa esse texto no lugar da tela.

## Para que serve

Reúne os nós ativos do fluxo e os conceitos que a wiki já usa.

## Quem vê

Quem desenha uma tarefa.

## Onde fica

O editor está em `/task/[id]/flow`. Cada nó ativo tem **Abrir manual do nó**.

## O que a tela mostra

O manual, quando existe, separa visão geral, configuração, como usar, exemplos e referência.

{% hint style="info" %}
Se ainda não houver texto, a tela diz: "Ainda não há manual para este nó."
{% endhint %}

Cada página de nó desta aba diz o que aquele bloco faz no caminho que começa no Início. O passo a passo de campo continua no manual do editor. Se a frase acima aparecer, não há campo documentado para copiar.

## Campos

Os nós ativos estão no menu lateral desta aba.

## O que dá para fazer

Abrir o nó ativo e voltar ao editor.

[Editor de fluxo](/operations/fluxo)
{% endcontent-ref %}

## Limite atual

Estes nomes ficam só neste índice, sem página de uso: Switch, Filtro, Memória, Telegram, em branco, dashboard, relatório executivo, resumo em texto, slides, infográfico, cartão de alerta, storyboard e livro.

Switch, Filtro, Memória e Telegram aparecem como em breve. Os demais nomes dessa lista são designers, também sem página de uso. Não há passo para configurar nenhum deles aqui.

## Dúvidas comuns

**O nó está na paleta e esta página não tem o formulário.**
O formulário é o manual que abre no fluxo. Esta página explica o papel do nó. Se o manual disser "Ainda não há manual para este nó.", o passo a passo de campo ainda não foi publicado na tela.

**Por que Switch não tem página?**
Porque está em breve, junto com Filtro, Memória, Telegram e os designers. O índice registra o nome. Não há uso para ensinar.

**Anotação entra no resultado?**
Não. Anotação é nota no canvas, sem executar. A página dela explica isso.
