# Primeiros passos

Entre com o seu usuário e escolha o projeto no menu lateral. Várias telas, como a de conectores, só carregam depois que um projeto está selecionado.

No menu, as áreas desta primeira versão ficam nestes grupos:

**Força de Trabalho**

* Colaboradores digitais
* Copilots
* Interações humanas

**Orquestração e Execução**

* Atividades
* Tarefas
* Artefatos
* Execuções
* Conectores
* DataTables

A Torre de Controle reúne a visão do que está acontecendo na operação.

## Um caminho simples

1. Confira se o projeto certo está selecionado.
2. Crie ou abra um colaborador digital.
3. Crie uma tarefa para esse colaborador e defina quando ela roda.
4. Acompanhe o resultado na lista de tarefas, em Atividades e em Execuções.
