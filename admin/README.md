# Administração

Estas telas aparecem para quem administra.

* [DataTables](datatables.md) guarda dados estruturados para as tarefas e as execuções do projeto usarem.
* [Auditoria](auditoria.md) lista as ações registradas na plataforma.
* [Dispositivos](dispositivos.md) registra e gerencia os aparelhos ligados à conta.
* [Runners](runners.md) lista as instalações do Runner vinculadas a este projeto.
* [Usuários](usuarios.md) gerencia os usuários do projeto.
