# Usuários

**Usuários** fica em Administração e aparece para quem administra. A tela também se apresenta como **Gerenciar Usuários** e **Gerencie os usuários do projeto**.

A lista mostra os **Usuários Cadastrados** e quantos foram encontrados. A busca é **Buscar por nome ou e-mail...**. Dá para filtrar por perfil e limpar os filtros.

## Criar

**Novo Usuário** ou **Criar Usuário** abre o formulário "Preencha as informações para criar um novo usuário."

* **Nome Completo.** Mínimo de 3 caracteres.
* **Telefone.** Com DDD.
* **Perfil.** A opção de administrador se chama **Administrador**.
* **Idioma.** Português (Brasil), Inglês (EUA), Espanhol ou Português (Portugal).
* **Fuso Horário.**
* **Usuário Habilitado.**
* **Cargo** e **Setor**, quando o cadastro do projeto usa esses campos.
* **Papel no projeto.**

A criação confirmada mostra "Usuário criado com sucesso."

**Convidar Usuário** envia o acesso para quem ainda não está no projeto.

## Editar e ver

**Editar Usuário** altera os mesmos dados. **Visualizar usuário** abre as informações somente para leitura. **Atualizar Usuário** grava a edição e confirma "Usuário atualizado com sucesso."

A exclusão confirma "Usuário excluído com sucesso." A busca sem resultado mostra **Nenhum usuário encontrado**.
