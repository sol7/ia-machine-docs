# Auditoria

**Auditoria** lista as ações registradas na plataforma.

{% hint style="info" %}
Dentro de um projeto, o texto é: "Acompanhe as ações registradas no projeto."
{% endhint %}

A tela fica no menu de governança e aparece para quem administra.

Dá para filtrar por:

* **Evento.** Todos os eventos, ou um tipo específico.
* **Projeto.** Todos os projetos, ou o projeto aberto.
* **Usuário.**
* **Alvo.** O registro afetado.

O alvo pode ser uma tarefa, um colaborador digital, um projeto, um membro, uma sessão, um artefato, um perfil de geração ou um design system.

{% hint style="warning" %}
Quando o registro já foi excluído, a lista marca como excluída.
{% endhint %}

A **Origem** indica de onde a ação partiu.
